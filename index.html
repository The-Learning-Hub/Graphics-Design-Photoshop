04 — Digital Image Basics

Know these before you create your first document.

🔲 Raster vs. Vector

Raster images are made of tiny colored squares called pixels. Photoshop is mainly a raster editor. Enlarging a raster image too much makes it blurry or pixelated.

Vector graphics are made from mathematical paths and can scale without losing quality. Adobe Illustrator is the main vector tool. Photoshop does include vector shapes and type.

🌈 Color Modes

RGB (Red, Green, Blue) is used for screens: websites, social media and videos.

CMYK (Cyan, Magenta, Yellow, Black) is used for printing. Some bright screen colors cannot be printed exactly, so print colors may look duller.

Change mode in Photoshop: Image → Mode.

📐 Resolution (PPI)

PPI means pixels per inch. Common starting points: 72 ppi for screen work and 300 ppi for print. Try the calculator:

Width (in) Height (in) PPI

Click Calculate to see the pixel size.

💾 Common File Formats

  • .PSD — Photoshop's own format. Keeps all layers so you can edit later. Always save one!
  • .JPG / JPEG — small photos for sharing. Lossy compression, no transparency.
  • .PNG — supports transparent backgrounds. Great for logos and web graphics.
  • .GIF — limited colors and simple animation.
  • .TIFF — high-quality format often used in print workflows.
  • .PDF — documents and print-ready files.

06 — Layers: The Heart of Photoshop

Think of layers as transparent sheets stacked on top of each other.

🧪 Layer Playground

DESIGN

Circle opacity:

📚 Why layers matter

  • Non-destructive editing — change one element without damaging others.
  • Order matters — layers higher in the Layers panel appear in front.
  • Visibility (eye icon) — hide or show any layer.
  • Opacity — make a layer more transparent.
  • Blend modes — control how a layer mixes with those below, such as Multiply or Screen.
  • Layer masks — hide parts of a layer without erasing. Paint black to hide, white to reveal.
  • Adjustment layers — change brightness, color and contrast without altering the original pixels.
  • Smart Objects — allow you to scale or filter an image without permanent damage.
Golden rule: Name your layers and avoid working directly on the original photo. Duplicate it first with Ctrl+J.

✨ Smart Features in Photoshop 2021/2022

Helpful modern tools. Availability can depend on your exact version and an internet connection.

🎯 Object Selection

Draw a rectangle or loop around an object and Photoshop detects it. Found with the Quick Selection / Magic Wand group (W).

🌅 Sky Replacement

Swap a dull sky for a new one automatically. Edit → Sky Replacement.

🧠 Neural Filters

AI-powered filters such as Skin Smoothing and Style Transfer. Filter → Neural Filters. Some download on first use.
